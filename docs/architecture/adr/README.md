# Architecture Decision Records

One file per decision that is expensive to reverse: a datastore, a protocol, a
service boundary, a language or framework choice.

## Process

1. Copy `0000-template.md` to `NNNN-short-title.md`, numbering sequentially.
2. Open it as `Proposed` in a pull request and link it from the description.
3. Once merged, set the status to `Accepted`.
4. Never rewrite an accepted ADR. Supersede it with a new one and mark the old
   record `Superseded by ADR-NNNN`.

The value is the *reasoning*, not the outcome — write down the options you
rejected and why.

# @atlas/core

Domain model for Project Atlas: entities, value objects, and the business rules
that operate on them.

**Status:** placeholder — no implementation yet.

## Rules

- Pure TypeScript. No HTTP clients, no database drivers, no UI framework.
- Runtime-agnostic: must run unchanged in a browser and in Node.
- This is the shared vocabulary. When apps and services disagree about what a
  term means, the answer is defined here.

# @atlas/mobile

Cross-platform mobile client (iOS and Android).

**Status:** placeholder — no implementation yet.

## Responsibilities

- Mobile-native Atlas experience, including offline-tolerant reads
- Push notification handling and device session management

## Notes

Shares domain types and API access with the web app through `@atlas/core` and
`@atlas/api-client`. Platform build tooling (Gradle, Xcode) is added here, not
at the repo root.
